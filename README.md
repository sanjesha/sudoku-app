# sudoku-app

A web-based Sudoku game with daily puzzles, difficulty levels, and leaderboards.

## Structure

- `web/` — React + TypeScript frontend (Vite)
- `api/` — Spring Boot backend (coming in Phase 2)
- `infra/` — Terraform configurations (coming in Phase 3)
- `shared/` — Shared TypeScript types (coming in Phase 2)
